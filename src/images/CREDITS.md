## Adding stock photos

Use only **Unsplash** (unsplash.com/license) or **Pexels** (pexels.com/license) photos.
Save them into `src/images/stock/` with these names (any of .jpg / .png / .webp):

| File name | Used on |
|---|---|
| `home.jpg` | Home hero ("For Homes") |
| `factory.jpg` | Home hero ("For Industry") |
| `residential.jpg` | Home "Built for both worlds", Applications → Residential |
| `industrial.jpg` | Home "Built for both worlds", Applications → Industrial |
| `about-hero.jpg` | About page parallax hero (currently a Pexels photo, see above) |

Then record each one below and run `npm run build`.

| File | Photographer | Source URL | Licence |
|---|---|---|---|
| _e.g. home.jpg_ | _Name_ | _https://www.pexels.com/photo/…_ | Pexels licence |
